# Operator Dashboard

**Status: design only; implementation not started.**

Planned React and TypeScript operations console with overview, transformer detail, alerts/actions, devices, scenarios, system-health screens, and a read-only incident-investigation drawer. The drawer streams bounded agent progress and presents observations, hypotheses, unknowns, and clickable evidence without merging model text into authoritative state. UI work is paired with ownership of the distributed projection/SSE delivery layer rather than treated as a standalone frontend assignment. See the [UI design](../docs/design/UI_DESIGN.md), [agent design](../docs/design/AGENTIC_COPILOT.md), and [Member_4's work plan](../docs/team/04_MEMBER_4_REALTIME_UI.md).
